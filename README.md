# RACKDOWN

First-person night shift on an ML server rack. Close the ticket, or melt the hall.

Drag to look around. Keys 1–0 are the tools. Q, F, and G are one-shot commissary tools when you own them. E slides a sled, swaps a part, seats a cable, or posts the job on HEAD-01.

```bash
npm install
npm run dev
```
